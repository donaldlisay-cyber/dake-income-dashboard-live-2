## 二、接单三问 ⭐ 立刻启用

> 任何一单，先问这三个问题。不要嫌麻烦 —— 这三个问题决定了你是在"谈合作"还是在"被派单"。

### 问法

```
1. 品牌方是谁呀？是品牌直接采买，还是代理那边转过来的？
2. 这个项目的预算大概在什么区间？
3. 付款周期是多久？大概多久能结？
```

### 为什么要问

| 问题 | 作用 |
|---|---|
| 问品牌方 | 判断直客单 vs 转包单，决定报价策略 |
| 问预算 | 打破信息不对称，让对方知道你在意价格 |
| 问账期 | 前置风险，避免 326 天的坑 |

### 对方不回答怎么办

```
"了解～那这样，我这边先报个价：
图文 ¥8,000，视频 ¥12,000。
如果预算有差距，您跟我说，我们找个都能接受的方式。"
```

**核心**：对方不透露预算，你就**先报自己的价**。
**先报价的人，掌握锚点。**

## 三、直客开发话术

### 3.1 联系已有直客（小鹏）谈年度框架

**为什么先做这个**：小鹏 5 笔贡献 ¥107,000，是唯一验证过的优质直客。

```
X 老师您好～

之前几次合作的数据我这边都整理了一下，效果都挺不错的，
也感谢您一直以来的信任。

想跟您聊聊长期合作的可能性：
我们能不能做个年度框架？比如我这边保证每月 X 条内容，
单价上可以给到比单次合作更优的价，同时排期优先保证。

这样您那边预算好规划，我这边也能更深入地做内容准备，
对品牌调性也会更熟悉，效果应该会更好。

您看这个方向可行吗？方便的话我们可以约个时间细聊～
```

### 3.2 从内容"钓"直客（每次创作都用）

**做法**：内容里自然带出品牌，同步 @ 官微。

```
（内容本身写完后，末尾自然带一句）

……整体体验下来，这台车的智驾在城区路况的表现超出预期。
@XX汽车
```

**注意**：
- 必须是**真实体验**，不能硬夸（你的风格也不允许）
- @ 的是**官微**，不是老板个人号
- 你的犀利风格在这里反而是优势 —— **真实吐槽比无脑吹更有说服力**

**品牌方看到后，通常会私信你**。这时候你的谈判地位完全不同：
不是你求合作，是**他想把这条自然内容放大**。

### 3.3 中介单转直客

**当接到一个高价中介单时**：

```
X 老师，这单我接了～ 另外想问下，
后续如果有类似的合作，方便直接跟品牌那边的对接人沟通吗？
我这边可以更直接地理解需求，改稿效率也会高一些，
您那边也省一道转达的功夫。
```

**成功率不高，但值得试**。有些中介会答应（省他事），有些不会。
**试 10 次，成 2 次就是胜利** —— 那是 2 个直客。

### 3.4 拒绝低价单（不伤和气版）

```
X 老师，感谢想到我～

不过这个价格（¥3,500）我这边确实接不了了，
现在图文内容我的标准价是 ¥8,000，
低于这个数我cover不住时间成本，做出来质量也不好保质保量。

如果是长期合作、条数多，我可以申请个优惠价，
您看那边有没有调整的空间？

如果没有的话，这次就先不合作了，后面有机会再联系～
```

**要点**：
- **给台阶**（"长期合作可以优惠"）
- **留后路**（"后面有机会再联系"）
- **不解释太多**（越解释越像心虚，报价是权利不是请求）

## 四、附：什么时候该涨价

出现以下任意一条，就该涨价：

- [ ] 连续 3 个月档期排满
- [ ] 同一个客户复购 3 次以上
- [ ] 你的内容多次自然上热搜
- [ ] 有品牌主动找来（非中介）
- [ ] 拒单率超过 30%（说明报价偏低）

**涨价幅度**：每次 **+20–30%**，不要一次翻倍（会吓跑客户）。

**涨价话术**：

```
X 老师，跟您说个事～
从 X 月开始，我这边的报价要调整到 ¥X,XXX 了，
主要是内容投入和制作成本都在涨。

不过咱们合作这么久了，您这边我按老价格再多做 1–2 单，
之后按新价走。您看可以吗？
```

**核心**：**老客户给过渡期**，体现尊重，也降低流失。
