# 从「等广告找上门」到「主动卖」

> 基于 103 笔真实商务单拆解 ｜ 2026-09-12
> 核心判断：**被动接单不是运气好，是把定价权让渡出去了。**

---

## 一、先看清你的真实处境

### 1.1 数字暴露的真相

| 指标 | 数据 | 说明 |
|---|---|---|
| 商务单总数 | 103 笔 | 2025/1 – 2026/9 |
| 商务总收入 | ¥412,800 | 占全期收入 40.5% |
| **单笔中位数** | **¥3,500** | 典型的"中介一口价" |
| **¥3,500 固定档** | **66 笔 / ¥197,900** | **占订单量 64%** |
| 品牌直客均价 | **¥14,250** | 小鹏 5 笔 ¥107,000 |
| 中介派单均价 | **¥3,500** | 票叔/Charlotte/C |
| **价差** | **4 倍** | 同一个人、同一个平台 |

### 1.2 最扎心的对比

```
小鹏（品牌直客）  5 笔  ¥107,000   均价 ¥14,250
票叔（中介派单）  14 笔 ¥55,500    均价 ¥3,964
```

**同样是你写一条内容，直客给 ¥14,250，中介给 ¥3,500。**

这不是内容质量的差异 —— 小鹏的试驾内容和影评内容，你的投入其实差不多。
这是**渠道结构**的差异：品牌直客按"传播价值"付费，中介按"产能成本"付费。

### 1.3 一个残酷的推论

票叔接一条影评的品牌预算，很可能是 ¥8,000–10,000。
他分给你 ¥3,500，**中间那 50–65% 是纯粹的渠道差价**。

你承担了：创作、风险、账期（最长 326 天）、平台处罚风险（禁言）。
他承担了：接单、转包。

**这个结构里，你不是"创作者"，你是"产能"。**

## 二、为什么会变成这样（三个失权点）

### 失权点 1：需求不透明

**你从来不知道品牌实际给了多少钱。**

中介的价值本来是"信息撮合"，但在你的case里，它变成了"信息封锁"。
你不知道预算池有多大，所以无法判断 ¥3,500 是高是低。

**破法**：每次接单都问一句 —— **"这个项目品牌给的预算是多少？"**
对方不一定说，但**你问了这个动作本身，就改变了双方的位置**。
问多了，对方知道你不是"随便给多少都接"的人。

### 失权点 2：没有报价单

**66 笔订单全落在 ¥3,500 这个价位，说明你从未主动报过价。**

被动接单的人，价格是"对方给的"；主动卖的人，价格是"自己定的"。

**破法**：做一份报价单，挂出去。哪怕一开始没人按这个价买，
**有了报价单，你就有了谈判的锚点**。

### 失权点 3：没有复购机制

**103 笔单里，只有小鹏算"回头客"（5 笔），而且仍然是对方找你。**

中介每次都能派单给你，是因为**他手上有稳定的客户**。
你每单都是"新的"，因为**你没有自己的客户**。

**破法**：把每一次合作都变成"建立直接联系"的机会。

## 三、转型路径：三个阶段，先易后难

```
阶段一（1个月）：立规则 —— 有报价、有底线
阶段二（3个月）：建直客 —— 绕开中介，直接对接品牌
阶段三（6-12月）：卖资产 —— 从卖时间变成卖产品
```

---

## 阶段一 · 立规则（1 个月内）

### 1.1 做一份报价单 ⭐ 最优先

**这是转型的第一步，也是投入产出比最高的一步。**

#### 报价单要包含什么

| 项 | 内容 |
|---|---|
| **内容类型** | 图文 / 视频 / 直播 / 联名 |
| **平台** | 微博 / 抖音 / 双平台打包 |
| **刊例价** | 你的标价（**要敢标高**） |
| **打包价** | 双平台、多篇的组合价 |
| **排期** | 需要提前几天预约 |
| **不接的范围** | 明确写出（如金融、医美、竞品排他） |

#### 定价基准怎么定

参考你的真实数据反推：

```
你的微博日均分成 ≈ ¥230–360
一条中等热度的博文，传播价值 ≈ 你的自然流量 × 行业CPM

汽车/数码类 CPM ≈ ¥28–38（微博）
按你 50 万粉量级、正常互动，单条商业内容合理区间：¥8,000–20,000
```

**关键**：你现在的 ¥3,500 是**中介价**，不是**你的价**。
你的报价单应该从 **¥8,000 起标**，直客谈 ¥12,000–15,000。

> ⚠️ 一开始可能没人按这个价买，没关系。
> **报价单的作用是"锚定"**，不是"成交"。
> 有了 ¥8,000 的锚，¥5,000 的offer 你就知道该不该接了。

#### 报价单放在哪

- 微博置顶一条（简洁版：合作请私信 + 报价区间）
- 主页简介挂链接
- 每次商务沟通直接发一份 PDF/图片

### 1.2 建立"接单三问" ⭐ 立刻可用

以后**任何一单**，先问这三个问题：

```
1. 品牌方是谁？（是品牌直采，还是代理转包？）
2. 这个项目的预算是多少？（不知道也问）
3. 付款周期多久？（写进合同）
```

**为什么这招管用**：
- 问品牌方 → 你能判断这是直客单还是转包单，决定报价策略
- 问预算 → 打破信息不对称，至少让对方知道你在意价格
- 问付款 → 把账期问题前置，避免 326 天的坑

### 1.3 设一条底线价

**低于底线价，宁可不接。**

你的底线价建议：**¥5,000**（图文）/ **¥8,000**（视频）

理由：
- ¥3,500 那些单，扣掉平台抽成（云账户代扣）、时间成本，实际到手很低
- 接低价单会**固化你"便宜"的标签**，越接越难涨价
- 你的时间有限，低价值订单挤占了高价值订单的机会

> **反直觉但重要**：拒绝低价单，短期收入会掉，但长期报价能力会回来。

## 阶段二 · 建直客（3 个月内）

### 2.1 从"中介的供应商"变成"品牌的合作方"

**你现在的位置**：
```
品牌 → 中介（票叔）→ 你
```

**目标位置**：
```
品牌 → 你        （直客）
品牌 → 中介 → 你  （保留，但只是补充）
```

### 2.2 具体做法：三条路径并行

#### 路径 A：把现有直客做深 ⭐ 最优先

**你已经有直客了，只是没经营。**

| 直客 | 笔数 | 金额 |
|---|---|---|
| 小鹏 | 5 笔 | ¥107,000 |
| 小米（杜长军） | 22 笔 | ¥77,800 |
| 日产 / 智己 | 各 1 笔 | 小额 |

**动作**：
1. 主动联系小鹏的对接人（不是等下次）
2. 表达"长期合作意愿"，谈**年度框架**
3. 框架的核心：**保底条数 + 优惠单价 + 优先排期**

```
参考话术：
"X 老师，之前几次合作效果都不错，想跟您聊聊长期合作的可能性。
我们能不能做个年度框架？比如保证每月 X 条，单价上我可以给到
比单次合作更优的价，同时排期优先。这样您那边预算也好规划。"
```

**为什么有效**：品牌方最怕"每次都要重新找博主、重新谈价"。
**你主动提供"省事方案"，就从"供应商"变成"合作伙伴"。**

#### 路径 B：从内容里"钓"直客

**做法**：在每次创作时，**主动 @ 品牌方**。

- 测了日产 N6 → @ 东风日产
- 聊了小米 → @ 小米汽车
- 评了某款车 → @ 品牌官微

**逻辑**：品牌方的市场部每天在看舆情。
你的内容如果自然带出品牌（非硬广、真实体验），**他们看到就会来找你**。

**这比等中介派单强 10 倍**：
- 你是"主动提及"，谈判地位高
- 品牌看到的是"自然内容"，效果数据更好
- 绕开了中介，直接建立联系

#### 路径 C：进入品牌的"创作者池"

**主流品牌都有官方创作者招募计划**：
- 汽车：各家都有"媒体/达人合作"入口
- 数码：华为/小米有开放的合作平台

**动作**：把你最满意的 3–5 条汽车内容，整理成一份"作品集"，投递过去。

### 2.3 降低对中介的依赖（渐进式）

**不要一刀两断**（中介当前仍是重要收入来源），而是：

| 中介单类型 | 处理方式 |
|---|---|
| 高价单（>¥8,000） | 接，但要求**介绍品牌方直接沟通** |
| 中价单（¥5,000–8,000） | 视档期接 |
| 低价单（<¥5,000） | **拒绝**，或要求涨价 |
| 老赖渠道（票叔） | **要求预付 50%**，否则不接 |

## 阶段三 · 卖资产（6–12 个月）

### 3.1 从"卖时间"到"卖产品"

```
现在：一条内容 = 一次收入（做完就没了）
目标：一个产品 = 持续收入（睡觉也在卖）
```

### 3.2 三条路径（按你的资源排序）

#### 路径 A：付费社群 ⭐ 最适合你

**为什么适合**：
- 你的粉丝黏性强、互动高（争议话题天然带社群属性）
- 你有"汽车评测 + 时事评论"的双重专业度
- 现金流稳定，且**社群本身就是商务议价筹码**（"我有 X 万付费用户"）

**产品设计**：
```
名称：汽车消费决策群 / 内容创作者交流群
定价：¥199–499/年
内容：每周 1 次深度分享 + 日常答疑
规模目标：500 人 = ¥10万–25万/年（半被动收入）
```

#### 路径 B：知识付费 / 课程

**你的可教内容**：
- 《汽车内容评测方法论》（你的 #大v聊车# 已经验证）
- 《争议话题的内容风险管理》（你踩过坑，最有发言权）

**优点**：一次生产，长期售卖，**毛利率最高**

#### 路径 C：IP 联名 / 分成合作

从"接单"升级为"分成"：
- 不再要固定费用，而是**按销售/线索分成**
- 适合汽车（线索分成）、消费品（销售分成）

**风险**：需要判断品牌靠谱度，建议在**已有信任基础的品牌**上试（如小鹏）。

## 六、三个必须扭转的认知

### 认知 1：广告找上门 ≠ 实力强，而是"你没定价权"

中介为什么找你？因为你**便宜、好用、不闹**。
真正实力强的标志是：**你能拒绝不合理的价格，并且对方还来找你**。

### 认知 2：¥3,500 不是市场价，是"中介价"

你的真实市场价应该参考品牌直客的 ¥14,250。
中间的差额不是你的内容不值钱，是**渠道结构吃掉了**。

### 认知 3：拒绝低价单不是"损失"，是"投资"

每接一个 ¥3,500 的单，你都在：
- 消耗时间（本可用于高价值内容）
- 固化"便宜"的标签
- 帮中介赚了差价

**宁可空着，也不贱卖。** 空档期用来做直客内容，比接低价单回报高得多。

---

## 七、一句话总结

> **你现在的问题不是"没有客户"，是"客户都握在中介手里"。**
>
> 转型的核心只有一件事：**把"客户"从别人手里，变成自己手里的。**
>
> 报价单是第一步 —— 不是为了卖，是为了**让所有人知道你有价格**。
